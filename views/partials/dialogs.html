Environment variables

ค่าที่บันทึกที่นี่จะถูกเขียนเป็นไฟล์ .env ให้ release ถัดไป release ที่กำลังทำงานอยู่ไม่เปลี่ยน แก้ได้ทั้งไฟล์หรือทีละรายการ แล้วกด "บันทึก ENV" ก่อนไปขั้นถัดไป

การอัปโหลดจะเพิ่ม key ใหม่และเขียนทับ key ที่ชื่อซ้ำ ลบบรรทัดเพื่อลบ key และเขียน KEY= เพื่อบันทึกค่าว่าง ค่าที่บันทึกถูกเก็บบน host และปิดบังใน log

ยังไม่มีการเปลี่ยนแปลง
