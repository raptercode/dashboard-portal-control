Monitor Logs Token

Token แบบอ่านอย่างเดียวสำหรับให้ระบบภายนอกดูสถานะ deploy ของโปรเจคเดียว ไม่เปิดเผย runtime log, secrets หรือ URL ของ repository ยกเลิกได้ทุกเมื่อด้วยปุ่ม Revoke

Token แสดงครั้งเดียว

ค่า token จะแสดงบนหน้านี้เพียงครั้งเดียวหลังสร้าง คัดลอกเก็บทันที ถ้าทำหาย ให้ Revoke แล้วสร้างใหม่
