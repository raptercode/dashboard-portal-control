สรุปก่อนบันทึก

ตรวจค่าด้านล่างอีกครั้ง ถ้าต้องแก้ให้กด "ย้อนกลับ" ค่าที่แสดงยังไม่ถูกบันทึกบน host

เมื่อกด "บันทึกและ sync source" ระบบจะ

บันทึกการตั้งค่าโปรเจคและพอร์ตที่กันไว้ แล้ว clone หรือ sync source จาก branch ที่เลือกมาไว้บน host ขั้นนี้ยังไม่ build ไม่สร้าง release และยังไม่รันแอป

ขั้นถัดไปหลัง sync สำเร็จ

เปิดเมนู Deploy ของโปรเจค บันทึก .env อย่างน้อยหนึ่งค่า แล้วจึงสร้าง candidate release แรกได้
