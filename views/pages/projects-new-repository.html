การตั้งค่าโปรเจค

Port, runtime, การรัน และ health check

Port

พอร์ต loopback ที่กันไว้ให้โปรเจคนี้บน host ระบบส่งค่าให้แอปทาง PORT และใช้เป็นปลายทางของ reverse proxy

Runtime

กำหนดวิธี install, build และรันแอป กด "ตรวจ App อัตโนมัติ" เพื่อให้ระบบเสนอ runtime และ framework จาก repository

Node.jsbuild และ run ด้วย npm script ใน systemd
Frameworkตรวจจาก repository และเปลี่ยนได้

การรัน

คำสั่งที่ระบบเรียกในโฟลเดอร์ release ใหม่ทุกครั้งที่ deploy แอปต้องอ่าน PORT จาก environment

Directory ต้องมี go.mod ใช้ . เมื่อ main อยู่ที่ root หรือ ./cmd/api สำหรับ package ย่อย ระบบจะ build เป็น binary ก่อนรันทุก release
Python environment
ไฟล์ .py เช่น main.py หรือ src/server.py แอปต้องอ่าน PORT จาก environment
สร้าง .venv แยกในแต่ละ release ติดตั้งและรันด้วย user ของโปรเจค ไม่ใช้ sudo pip หรือ Python packages ของระบบ
PHP environment
PHP built-in server ฟัง PORT บน loopback ใส่ router เมื่อแอปใช้ front controller เช่น public/index.php

Health check

ด่านสุดท้ายก่อนสลับ traffic ระบบยิง HTTP ไปที่ candidate บน loopback และจะ activate เมื่อผ่านเท่านั้น

ส่ง HTTP GET ไปที่ candidate บน loopback ต้องได้สถานะ 2xx หรือ 3xx ภายในเวลาที่กำหนดจึงผ่าน ถ้าไม่ผ่าน release ปัจจุบันจะทำงานต่อ
ย้อนกลับ ยังไม่บันทึก ขั้นถัดไปจะสรุปค่าทั้งหมดให้ตรวจอีกครั้ง
