Runtime
Node.jsbuild และ run ด้วย npm script ใน systemd
Frameworkตรวจจาก repository · เปลี่ยนได้
Directory ต้องมี go.mod · ใช้ . เมื่อ main อยู่ที่ root หรือ ./cmd/api สำหรับ package ย่อย · แอปต้องอ่าน PORT จาก environment · build ทุกครั้งก่อนรัน binary
Python environment
ไฟล์ .py เช่น main.py หรือ src/server.py; แอปต้องอ่าน PORT จาก environment
สร้าง .venv แยกในแต่ละ release · ติดตั้งและรันด้วย user ของโปรเจกต์ · ไม่ใช้ sudo pip หรือ Python packages ของระบบ
PHP environment
PHP built-in server ฟัง PORT บน loopback; ใส่ router เมื่อแอปใช้ front controller เช่น public/index.php
Health check
ส่ง HTTP GET ไปที่ candidate บน loopback; สถานะ 2xx หรือ 3xx ภายในเวลาที่กำหนดจึงผ่าน
