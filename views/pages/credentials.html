Credentials

จัดการ HTTPS token แยกตามองค์กร สมาชิกใช้และจัดการได้ตามสิทธิ์ Token เก็บแบบเข้ารหัสและไม่แสดงค่าเดิมอีก

รายการและค่าเริ่มต้นใช้เฉพาะองค์กรที่เลือก

Token ที่บันทึกไว้

ตั้ง default ได้หนึ่งรายการต่อองค์กร ระบบเลือกเมื่อ Git host ตรงกัน Token ที่โปรเจคยังใช้อยู่จะลบไม่ได้

เพิ่ม HTTPS token

Token ถูกเข้ารหัสก่อนบันทึก สามารถเปลี่ยน token ภายหลังโดยโปรเจคยังใช้ credential เดิมได้
