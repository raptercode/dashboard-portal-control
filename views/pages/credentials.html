Credentials

Token สำหรับดึง private repository ผ่าน HTTPS เก็บแบบเข้ารหัสบน host นี้และไม่ส่งกลับผ่าน API

Token ที่บันทึกไว้

ตั้ง default ได้หนึ่งรายการ Portal จะเลือกให้อัตโนมัติเมื่อสร้างโปรเจคจาก host เดียวกัน token ที่โปรเจคยังใช้อยู่จะลบไม่ได้

เพิ่ม HTTPS token

Token ถูกเข้ารหัสก่อนบันทึก หลังจากนี้จะดูค่าเดิมไม่ได้อีก ถ้าต้องเปลี่ยนให้ลบแล้วเพิ่มใหม่
