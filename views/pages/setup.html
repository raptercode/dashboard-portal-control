Setup

เตรียม host นี้ให้พร้อมสำหรับ deploy ทั้งเครื่องมือ mail server และชื่อผู้สร้าง commit

การติดตั้งทุกครั้งผ่าน helper ที่จำกัดสิทธิ์

Portal สั่งติดตั้งได้เฉพาะเครื่องมือใน allowlist ผ่าน privileged helper และทุกคำสั่งถูกบันทึกไว้ในหน้า Activity

เครื่องมือบน host

เครื่องมือที่ Portal ใช้ build และ deploy โปรเจค รายการที่จำเป็นต้องติดตั้งครบก่อน deploy ครั้งแรก

ความพร้อมของ Mail server

ทดสอบว่า host นี้ส่ง SMTP ขาออกได้จริงหรือไม่ และอ่าน policy firewall ขาเข้าเพื่อเลือกวิธีส่ง mail ที่เหมาะกับเครือข่ายนี้

ยังไม่เคยทดสอบ การทดสอบจะลองเชื่อมต่อขาออกที่พอร์ต 25, 587 และ 2525 แล้วอ่าน policy firewall ขาเข้าของพอร์ต 25, 587 และ 993

ใช้เวลาราว 10 วินาที ไม่มีการเปลี่ยนแปลงใดบน host

Git identity

ใช้เป็นชื่อและอีเมลผู้สร้าง commit ที่ Portal ทำแทนคุณเท่านั้น ไม่ใช่ credential สำหรับเข้าถึง repository
