Monitor Logs Token

Token แบบอ่านอย่างเดียวสำหรับให้ระบบภายนอกดูสถานะ deploy ของโปรเจคเดียว ไม่ส่ง runtime log, build output, ค่า ENV/credential ที่เก็บไว้ หรือ URL ของ repository แต่ยังมีข้อความสรุปและเหตุการณ์ของ deploy ยกเลิกได้ทุกเมื่อด้วยปุ่ม Revoke

Token แสดงครั้งเดียว

ค่า token จะแสดงบนหน้านี้เพียงครั้งเดียวหลังสร้าง คัดลอกเก็บทันที ถ้าทำหาย ให้ Revoke แล้วสร้างใหม่
