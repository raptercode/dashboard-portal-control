# Mail: โดเมน, mailbox และกล่องอีเมลใน Portal

[English](../../en/how-to/mail.md)


ใช้หลังจากตั้งค่า mail service ครั้งแรกที่ `/mail/setup` แล้ว ทุกอย่างในหน้านี้ต้องใช้บัญชี Master เหตุผลของการออกแบบอยู่ใน [ADR 0025](../knowledge/adr/0025-port-aware-mail-host-provisioning.md) และ [ADR 0033](../knowledge/adr/0033-mail-domains-apply-at-once-and-the-portal-reads-mailboxes.md)

## อ่านและส่งอีเมล

เปิด **Mail** จะเห็น Inbox ของ mailbox แรก

- ถ้า host มีหลาย mailbox เลือกจากรายการใต้ปุ่ม **Compose**
- **Inbox**, **Sent**, **Drafts**, **Spam**, **Trash** เป็นโฟลเดอร์เดียวกับที่โปรแกรมอีเมลเห็นผ่าน IMAP ตัวเลขข้างโฟลเดอร์คือจำนวนที่ยังไม่อ่าน
- กดที่ข้อความเพื่ออ่าน การเปิดจะทำเครื่องหมายว่าอ่านแล้ว **Reply**, **Reply all**, **Forward** เปิดหน้าต่างเขียนอีเมลพร้อมข้อความเดิมที่อ้างถึง
- **Compose** เปิดหน้าต่างที่มุมล่างขวา และเปิดค้างไว้ได้ระหว่างเปลี่ยนโฟลเดอร์ อีเมลที่ส่งแล้วเก็บใน **Sent**
- การลบย้ายข้อความไป **Trash** การลบจาก Trash คือลบถาวร **Restore** ใน Trash และ **Not spam** ใน Spam ย้ายกลับ Inbox
- รายการ refresh เองทุก 30 วินาทีเมื่อเปิดหน้าแรกของโฟลเดอร์

อีเมลแบบ HTML แสดงใน frame ที่แยกจากหน้าเว็บ รูปที่โหลดจากอินเทอร์เน็ตถูกปิดไว้ เพราะการโหลดทำให้ผู้ส่งรู้ว่าคุณเปิดอ่าน กด **แสดงรูป** เพื่อโหลดเฉพาะข้อความนั้น ไฟล์แนบเป็นการดาวน์โหลดเสมอ ไม่เปิดใน Portal

สิ่งที่ยังทำไม่ได้: แนบไฟล์ในอีเมลใหม่ บันทึก draft ค้นหา และรวมข้อความเป็น conversation

## เพิ่มโดเมน

1. **Mail → Domains**
2. กรอกโดเมนแล้วกด **Add domain**

โดเมนใช้งานบน host ได้ทันที ไม่ต้องตรวจ DNS ก่อน และไม่ต้องกด **Activate** ซ้ำ สร้าง mailbox ใต้โดเมนนั้นได้เลย

โดเมนจะเปิดแสดง DNS records สี่รายการ แต่ละแถวมีชนิด **Host / Name** และ **Value** พร้อมปุ่มคัดลอก นำไปกรอกที่ผู้ให้บริการ DNS:

| Record | หน้าที่ |
| --- | --- |
| MX | ให้ server อื่นส่งอีเมลของโดเมนมาที่ host นี้ ถ้าไม่มีจะไม่มีอีเมลเข้า |
| SPF | ประกาศว่า host นี้ส่งอีเมลในนามโดเมนได้ |
| DKIM | ให้ผู้รับตรวจลายเซ็นที่ host นี้ใส่ในอีเมล |
| DMARC | บอกผู้รับว่าจะทำอย่างไรเมื่อ SPF และ DKIM ไม่ผ่าน |

Portal ตรวจ records ซ้ำให้เอง: ตอนเพิ่มโดเมน ตอนเปิดหน้า และทุก 90 วินาทีระหว่างที่ยังมี record ไม่ถูกต้อง ปุ่ม **ตรวจ DNS ตอนนี้** ใช้ตรวจทันที ระหว่างที่ยังไม่ครบสี่รายการ โดเมนจะแสดง `DNS n/4` อีเมลที่ส่งออกอาจถูกปฏิเสธหรือตกสแปมที่ปลายทาง และอีเมลขาเข้าจะยังไม่มาจนกว่า MX จะถูกต้อง

## ลบโดเมน

เปิดโดเมนแล้วกด **ลบโดเมน** host หยุดรับอีเมลของโดเมนนั้นทันที ถ้าโดเมนยังมี mailbox ระบบให้พิมพ์ชื่อโดเมนเพื่อยืนยัน และ mailbox ของโดเมนจะถูกลบออกจาก Portal ด้วย ไฟล์อีเมลที่เก็บไว้ใต้ `/var/vmail` ยังอยู่บน host

## Mailbox

**Mail → Mailboxes** แสดงทุกที่อยู่ **New mailbox** ต้องมีที่อยู่ โดเมน และรหัสผ่านอย่างน้อย 12 ตัวอักษร ปุ่ม **Generate & copy** สร้างรหัสผ่านและคัดลอกให้ Portal ไม่เก็บรหัสผ่านและแสดงซ้ำไม่ได้

**Open inbox** ไปที่ mailbox นั้นในกล่องอีเมล ถ้าต้องการใช้โปรแกรมอีเมลด้วย ดู **Mail → Server → Mail client settings** ซึ่งแสดงเฉพาะพอร์ตที่ firewall ของ host อนุญาต

## เมื่อไรต้องตั้งค่า service ใหม่

เฉพาะเมื่อเปลี่ยน mail hostname วิธีส่ง หรือ policy ของพอร์ต 25, 587, 993: **Mail → Server → Apply configuration again** การเพิ่มหรือลบโดเมนและ mailbox ไม่ต้องทำขั้นนี้

ถ้าเคยเพิ่มโดเมนไว้ก่อนเวอร์ชันนี้โดยยังไม่ได้ activate ซ้ำ การเพิ่มหรือลบโดเมนใดก็ได้ หรือกด **Apply configuration again** จะเขียนโดเมนนั้นลง host

## ข้อจำกัดและสิ่งที่ยังไม่ได้พิสูจน์

- กล่องอีเมลเปิดข้อความได้ไม่เกิน 30 MiB ข้อความที่ใหญ่กว่าให้ใช้โปรแกรมอีเมล
- Master อ่านได้ทุก mailbox ของ host ควรปกป้องบัญชีนี้ให้เหมาะสม
- ผลใน **Connectivity** เป็นหลักฐานของเครื่องนี้เท่านั้น firewall ของผู้ให้บริการยังบล็อกอีเมลขาเข้าได้ ข้อความจริงจากภายนอกคือหลักฐาน
- ขั้นตอนนี้มีเทสต์อัตโนมัติและทดลองในเบราว์เซอร์กับ sandbox ในเครื่องแล้ว แต่ยังไม่ได้ทำ acceptance บน host จริงที่มี Postfix, Dovecot และ OpenDKIM
