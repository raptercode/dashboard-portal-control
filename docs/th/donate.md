# สนับสนุน Strckro

[English](../en/donate.md) · [กลับหน้าโปรเจกต์](../../README.th.md)

ถ้า Strckro ช่วยประหยัดเวลาของคุณ เงินสนับสนุนจะช่วยให้พัฒนาและดูแลโปรเจกต์ต่อได้ ขอบคุณที่ใช้งานครับ

## ช่องทางรับเงิน

### พร้อมเพย์ (บาท)

สแกน QR ด้วยแอปธนาคารไทย ใส่ยอดที่ต้องการสนับสนุนเป็นเงินบาท แล้วตรวจชื่อผู้รับก่อนยืนยัน

<img src="../assets/qr_code.jpg" alt="QR พร้อมเพย์สำหรับสนับสนุน Strckro เป็นเงินบาท" width="360">

### USDT (Tether)

เลือก **BNB Smart Chain (BEP-20)** แล้วคัดลอกที่อยู่รับเงินจากหน้าหลัก [ดูที่อยู่รับ USDT](../en/donate.md#usdt-tether)

## สนับสนุนแบบอื่น

แชร์ Strckro ให้คนที่ดูแลเซิร์ฟเวอร์เอง แจ้งบั๊กพร้อมขั้นตอนที่ทำให้เกิดปัญหา หรือส่ง pull request เข้ามาได้ [GitHub repository](https://github.com/raptercode/Strckro) · [แจ้งปัญหา](https://github.com/raptercode/Strckro/issues)
